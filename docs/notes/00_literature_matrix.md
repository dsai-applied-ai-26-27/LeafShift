# Literature matrix - LeafShift

This is an initial 4-source matrix. It covers the project motivation, the two main datasets, and the planned visual explanation method. The team should read the full papers and add notes from the papers before the final submission.

| Source | Main question / contribution | Data and method | Main result or useful finding | How it supports LeafShift | Limitation / note |
|---|---|---|---|---|---|
| Hughes & Salathé (2015), *An open access repository of images on plant health to enable the development of mobile disease diagnostics through machine learning and crowdsourcing*. [arXiv:1511.08060](https://arxiv.org/abs/1511.08060) | Introduces an open image repository intended to support plant-health recognition research. | PlantVillage image repository and its crowdsourced/curated plant-health image collection. | Establishes the dataset resource used by later PlantVillage classification work. | Background source for where PlantVillage comes from and why it became a common benchmark. | Dataset copies and metadata may differ. Record the exact version and source used by this project. |
| Mohanty, Hughes & Salathé (2016), *Using Deep Learning for Image-Based Plant Disease Detection*. [Frontiers in Plant Science](https://doi.org/10.3389/fpls.2016.01419) | Tests deep learning for image-based crop/disease identification. | 54,306 PlantVillage images; CNN classification across 38 crop-disease classes. Also evaluates two small outside-source image sets. | Reports 99.35% accuracy on a held-out PlantVillage test set, but 31.40% and 31.69% accuracy on the two outside-source sets. | Directly motivates the lab-to-field gap that LeafShift investigates. It shows that high in-dataset performance does not guarantee similar performance on images from different conditions. | Outside-source test sets were small (121 and 119 images), and the result is not a direct PlantDoc comparison. |
| Singh et al. (2020), *PlantDoc: A Dataset for Visual Plant Disease Detection*. [ACM DOI](https://doi.org/10.1145/3371158.3371196) · [arXiv](https://arxiv.org/abs/1911.10317) | Introduces a dataset intended to support plant-disease recognition in less controlled visual conditions. | 2,598 internet-sourced images covering 13 plant species and up to 17 disease classes; annotations took about 300 human hours. | The authors report that training with PlantDoc can improve classification accuracy by up to 31% in their evaluated setting. | Provides the field/web-image dataset for the cross-dataset comparison and motivates careful label review. | Web-sourced images can vary in quality and may include several leaves or symptoms. Folder names and counts can vary between redistributed copies; inspect the exact copy. |
| Selvaraju et al. (2017), *Grad-CAM: Visual Explanations From Deep Networks via Gradient-Based Localization*. [ICCV Open Access](https://openaccess.thecvf.com/content_iccv_2017/html/Selvaraju_Grad-CAM_Visual_Explanations_ICCV_2017_paper.html) | Proposes a way to highlight image regions that influence a CNN prediction. | Uses gradients flowing into a final convolutional layer to produce a class-specific heatmap. | Grad-CAM can help inspect what visual regions contribute to a model's prediction and can reveal possible dataset bias. | Supports our planned comparison of attention on leaf symptoms versus backgrounds in PlantVillage and PlantDoc. | A heatmap is an interpretation aid, not proof of causal reasoning. It needs to be combined with controlled tests. |

## Main takeaways for our project

1. PlantVillage can produce very high test scores under its own image conditions, but Mohanty et al. show a large reduction on outside-source images.
2. PlantDoc provides a more varied source of images, but its web-sourced nature means labels and image quality need checking.
3. We should separate the data-quality question from the model question: first audit labels and duplicates, then train and evaluate the baseline.
4. Grad-CAM can help inspect model focus, but we should combine it with a background intervention and a human-reviewed PlantDoc subset.
